# VOID CORE 통합 디스코드 봇

판매 기능과 비공개 고객 문의 티켓을 하나로 묶은 discord.js v14 봇입니다. 아이폰에서는 파일 업로드/설정이 다소 불편할 수 있으므로 GitHub와 호스팅 서비스의 웹 화면을 이용해 배포할 수 있습니다.

## 포함 기능

### 고객 기능
- `/shop` : 상품 목록, 가격, 설명, 재고 표시 및 상품 선택 주문
- 상품 선택 시 주문 번호와 결제 안내를 개인 응답으로 표시
- `/my-orders` : 본인 주문 내역 확인
- 문의 패널의 `문의하기` 버튼: 고객과 담당자만 볼 수 있는 비공개 채널 자동 생성
- `문의 종료` 버튼: 작성자 또는 담당 관리자가 종료. 채널은 기록 보관을 위해 남기고 고객 접근을 차단
- 동일 고객은 열린 문의를 한 개만 가질 수 있음

### 관리자 기능
- `/ticket-panel` : 문의 패널 게시
- `/add-product` : 상품 등록
- `/add-stock` : 제품 키 재고 추가 (한 줄에 하나씩)
- `/approve` : 실제 입금 확인 후 주문 승인 및 제품 키 DM 지급
- `/orders` : 최근 주문 내역 확인
- `ORDER_LOG_CHANNEL_ID` 설정 시 신규 주문/지급 결과 알림

## 결제 방식의 중요한 제한

현재 버전은 결제 대행사(PG)와 연결되어 있지 않습니다. 고객 주문 후 결제 안내만 보여주며, 관리자가 실제 입금을 확인한 다음 `/approve order-id:<주문번호>`를 실행해야 합니다. 자동 결제/자동 입금 확인은 결제업체 공식 API와 웹훅을 별도로 개발·연결해야 합니다.

## Discord 개발자 포털 설정

1. 애플리케이션의 Bot 페이지에서 봇을 생성하고 토큰을 발급합니다.
2. OAuth2 URL Generator에서 `bot`과 `applications.commands`를 선택합니다.
3. 권한은 최소한 다음을 부여합니다.
   - View Channels
   - Send Messages
   - Embed Links
   - Read Message History
   - Manage Channels (문의 채널 생성/이름 변경/권한 변경)
4. 서버에 초대합니다. `Administrator` 권한은 필수가 아닙니다.

## 환경변수 설정

`.env.example`을 `.env`로 복사하고 다음 값을 입력합니다.

- `DISCORD_TOKEN`: 봇 토큰 (절대 공개 금지)
- `CLIENT_ID`: 애플리케이션 ID
- `GUILD_ID`: 봇 명령어를 등록할 서버 ID
- `PAYMENT_INFO`: 고객에게 보여줄 결제 안내
- `ORDER_LOG_CHANNEL_ID` (선택): 주문 로그 채널 ID
- `STAFF_ROLE_ID` (선택): 문의 담당자 역할 ID. 지정하면 해당 역할과 고객만 문의 채널을 볼 수 있습니다. 비워두면 고객과 봇, 서버 관리자(관리자 권한 우회)만 접근할 수 있습니다.
- `TICKET_CATEGORY_ID` (선택): 생성할 문의 채널의 카테고리 ID
- `DB_PATH` (선택): SQLite DB 경로

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
cp .env.example .env
# .env 값을 채운 후
npm start
```

Windows PowerShell에서는 `.env.example`을 복사해 `.env`로 이름을 바꾸면 됩니다.

## 첫 설정 순서

1. 봇을 서버에 초대하고 위 권한을 확인합니다.
2. `.env`를 설정하고 봇을 실행합니다.
3. 관리자 계정으로 `/ticket-panel`을 실행해 문의 패널을 게시합니다.
4. `/add-product`로 상품을 등록합니다.
5. `/add-stock`으로 제품 키를 등록합니다. 키는 한 줄에 하나씩 입력합니다.
6. 고객용 채널에서 `/shop`을 실행해 상점을 게시합니다.
7. 테스트 주문을 만든 뒤 실제 결제 확인 없이 `/approve`를 누르지 말고, 테스트용 키로 지급 흐름을 점검합니다.

## 운영 및 보안 주의

- 봇 토큰, 라이선스 키, `.env` 파일을 채팅/공개 저장소에 올리지 마세요.
- 토큰이 노출되면 Discord Developer Portal에서 즉시 재발급하세요.
- 구매자 DM이 차단되어 있으면 자동 전달이 실패할 수 있습니다. 이 경우 주문 상태는 `DM_FAILED`로 표시되고 재고는 중복 지급 방지를 위해 다시 풀지 않습니다. 관리자가 주문자와 확인해 안전하게 전달해야 합니다.
- SQLite 파일(`void-core.sqlite`)을 재배포/재시작 후에도 보존할 수 있는 영구 저장소에 두세요. 임시 파일 시스템에서는 데이터가 사라질 수 있습니다.
- 봇 초대 권한은 최소 권한을 권장합니다. `Administrator`는 필요하지 않습니다.
- 이 코드는 기본 템플릿입니다. 실제 판매 전 테스트 서버에서 문의 권한, 재고, 주문 승인, DM 실패 상황을 충분히 검증하세요.
